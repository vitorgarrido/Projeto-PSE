# Projeto PSE

## Sistema de Apoio ao Programa Saúde na Escola

Projeto desenvolvido como parte da Atividade de Estudo Programado (AEP) do curso de Engenharia de Software da Unicesumar.

## Sobre o projeto

O projeto consiste no desenvolvimento de um sistema de apoio ao Programa Saúde na Escola (PSE), buscando aplicar conhecimentos de programação, lógica de programação e desenvolvimento de software.

O sistema foi planejado a partir da contextualização do Programa Saúde na Escola, que promove ações de saúde e educação voltadas aos estudantes da educação básica.

## Objetivo

Desenvolver um sistema em linguagem C capaz de representar funcionalidades relacionadas ao contexto do Programa Saúde na Escola, utilizando conceitos de lógica de programação, estruturas condicionais, estruturas de repetição, funções e organização de dados.
