
# Testes do Sistema

Esta pasta contém os casos de teste elaborados para verificar o funcionamento do Sistema PSE em Ação.

## Arquivo

- `casos_de_teste.txt`: apresenta 13 casos de teste, incluindo cadastro, consulta, atualização, participação, validações e encerramento.

Os testes permitem verificar se as funcionalidades do sistema apresentam os resultados esperados.
