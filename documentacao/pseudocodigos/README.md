
# Pseudocódigos

Esta pasta contém os pseudocódigos elaborados para representar a lógica das operações do Sistema PSE em Ação.

## Arquivos

- `pseudocodigo-cadastro.txt`: apresenta a sequência lógica utilizada para cadastrar uma nova ação no sistema.

Os pseudocódigos auxiliam na compreensão dos algoritmos antes de sua implementação em linguagem C.
